手機網頁，查臺中市長照「交通接送服務（DA01／BD03）」的 39 家特約單位。
可以搜尋、依所在行政區篩選、打電話、開地圖，還能記錄每一家的聯絡狀況。

**紀錄是全家共用的** —— 存在自己的 Google 試算表，誰在哪台手機寫的都看得到。

👉 **https://alinalaipy.github.io/Long-term-care/**

```
iPhone（Safari／加到主畫面）
      │
      ▼
GitHub Pages  index.html          ← 純靜態網頁，沒有伺服器
      │  JSONP（免 CORS 設定）
      ▼
Google Apps Script  /exec         ← apps-script/Code.gs
      │
      ▼
Google 試算表
      ├─ 「紀錄」    每家單位的狀態／星號／筆記（共用一份）
      ├─ 「使用紀錄」誰、哪台手機、何時、搜尋什麼、打給誰
      ├─ 「裝置」    有哪幾支手機在用、各用了幾次
      └─ 「座標」    39 家單位的經緯度（只查一次，用來算距離）
```

## 家人怎麼用

傳邀請連結給他們（設定頁的「複製邀請連結」），打開後只要**輸入名字**就能用。
沒有連結的話，畫面會問通關密語，密語直接顯示在輸入格下面，點一下自動填。

進去之後建議：Safari 底部「分享」→「加入主畫面」，之後像 App 一樣一按就開。

## 功能

| 功能 | 說明 |
|---|---|
| 搜尋 | 單位名稱、行政區、地址、電話，連自己寫的筆記都搜得到。排序照相關程度：名字對到 > 地址在那 > 有服務到那區 |
| 我的地點 | 「用我現在的位置」抓 GPS；或輸入長輩家地址；也可直接點選 29 區。之後所有距離都以這個點為圓心 |
| 距離 | 每張卡片顯示離你的地點多遠，可切換「離我最近」排序。座標由 Apps Script 內建地圖服務查一次後存進試算表 |
| 地圖 | 清單／地圖切換，圖上依聯絡狀態標色，點圖釘（或圖釘附近）直接開明細。有設地點時以你為中心，右下角「◎」隨時回到自己的位置。縮放不會被關閉明細打斷 |
| 篩選 | 行政區、已聯絡／可接送／待確認、★ 已標記、有筆記 |
| 紀錄 | 五種聯絡狀態、星號、自由筆記，自動存檔並同步 |
| 一鍵動作 | 撥打電話、開 Google 地圖、複製單位資料 |
| 離線 | 沒網路照樣查、照樣寫，變更排隊，回到有網路自動補送 |
| 跟版 | 版本太舊會強制更新，家人不會停留在舊版 |
| 教學 | 聚光燈導覽：直接在真的畫面上圈出搜尋、我的地點、撥打電話、寫紀錄、地圖等七個位置，第一次使用自動帶一次，之後按頁首的「？」隨時重來 |

## 後端設定（第一次才需要）

1. 開一份 Google 試算表，複製網址中間那段 ID。
2. [script.google.com](https://script.google.com) 新增專案，貼上
   [`apps-script/Code.gs`](apps-script/Code.gs) 全部內容。
3. 改最上面兩行：
   ```js
   var TOKEN  = '你自己取的密語';   // 家人共用的通關密語
   var SS_ID  = '試算表 ID';
   ```
4. 存檔 → 上方函式選 `測試設定` → ▶ 執行 → 完成授權
   （「進階」→「前往專案」→「允許」）。三張工作表會自動建立。
5. **部署 → 新增部署作業 → 網頁應用程式**
   - 執行身分：**我自己**
   - 誰可以存取：**所有人** ← 選錯家人會打不開
6. 複製 `/exec` 網址 —— **不要**寫進程式碼，見下面「設定與鑰匙」。

> ⚠️ 之後每次改 `Code.gs`，都要**部署 → 管理部署作業 → ✏️ → 版本選「新版本」→ 部署**，
> 改動才會生效（網址不會變）。

## 設定與鑰匙

`index.html` 最上方：

```js
var APP_VERSION = 3;      // 網頁版本，跟 Code.gs 的 APP_VERSION 對應
var DEFAULT_API = "https://script.google.com/macros/s/.../exec";
var TOKEN_HINT  = "1234"; // 顯示在密語欄下面的提示；設成 "" 就不顯示
```

家人打開網址 → 輸入密語（畫面上有提示可以點一下自動填）→ 填名字 → 開始用。
也可以從設定面板「複製邀請連結」傳給他們，那樣連密語都自動帶入。

### 這是個刻意的取捨

網址寫在公開的程式碼裡，等於門沒有鎖 —— 拿到網址的人再猜中密語就進得來。

之所以這樣選：使用者是長輩。先前試過「網址只放在邀請連結裡、程式碼留空」的
做法，公開頁面確實變成空殼，但**連結一弄丟就永遠進不去**，實際使用時管理者
自己就被鎖在外面兩次。對這個用途來說，那個代價比被陌生人看到高得多。

真的想鎖起來的話：把 `DEFAULT_API` 和 `TOKEN_HINT` 設成 `""`，
系統會自動改成「只能靠邀請連結進入」的模式，程式已經支援。
但請先確定每位家人都把連結存好了。

### 換密語之後

家人不必記也不必打密語 —— 連結會自動帶入，他們手機上的名字也還留著，
點開新連結只要按一下「開始使用」。

但**已經加到主畫面的那台要注意**：iPhone 的主畫面 App 和 Safari 各自有
獨立的儲存空間，在 Safari 點新連結不會更新到主畫面那個圖示。兩種解法：

- 在主畫面 App 裡：設定 → **改用新的邀請連結** → 把連結貼上
- 或在進場畫面的「已經有連結了？貼在這裡也可以」直接貼

貼的時候前後多幾個字沒關係（例如整段 LINE 訊息一起複製），系統會自己
把 `?api=` 和 `&t=` 抓出來。

### 要強制所有家人更新時

改 `Code.gs` 這兩行，各 +1，然後重新部署：

```js
var APP_VERSION = 3;
var MIN_VERSION = 3;   // 低於這個版本一律擋下來要求更新
```

家人下次打開就會看到「請更新到新版才能繼續使用」，按一下就好。

## 試算表長什麼樣

**「紀錄」**

| 序號 | 單位名稱 | 狀態 | 星號 | 筆記 | 最後更新者 | 裝置 | 最後更新時間 |
|---|---|---|---|---|---|---|---|
| 100 | 財團法人臺中市私立童庭…基金會 | yes | ★ | 週二四上午可排 | 阿美 | D-K7M2Q | 2026/08/31 10:22 |

狀態代碼：`none` 未聯絡、`called` 已聯絡、`yes` 可接送、`hold` 待確認、`no` 不接。

可以直接在試算表裡改筆記，但**請順手把「最後更新時間」也改成現在** —— 系統用時間新舊決定誰蓋過誰。

**「使用紀錄」** 時間、使用者、裝置、動作、內容、序號、單位名稱。
會記錄：開啟名單、搜尋、篩選區域、設定地點、開啟、撥打、地圖、狀態、筆記、加星號、清除紀錄。

**「裝置」** 裝置代碼、暱稱、首次使用、最後使用、使用次數。
每支手機第一次開啟會自動產生固定代碼，改不掉，所以看得出來是誰做的。
進場一定要填名字才能使用，紀錄不會出現沒有署名的情況。

**「座標」** 序號、單位名稱、地址、緯度、經度、查詢時間。
第一次有人開啟時自動查一次就存起來，之後所有人共用，不會重複消耗額度。
地址改了想重查，把該列刪掉即可。

## 常見問題

**手機顯示「連不上雲端」**
- 部署時「誰可以存取」沒選 **所有人**（最常見）
- 網址結尾不是 `/exec`（`/dev` 只有自己登入時能用）
- 改了 `Code.gs` 但沒有重新部署新版本

**兩個人同時改同一家？** 以後改的為準，較舊那台會自動換成雲端版本。

**隱私** 通關密語是唯一的門檻，而網址就寫在這個公開 repo 裡，所以請把它當成
「半公開」的資料看待，別放個資。試算表本身仍然只有你和你分享的人打得開。
